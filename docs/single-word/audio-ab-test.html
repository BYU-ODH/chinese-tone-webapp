What this is

The production app always records with echoCancellation, noiseSuppression, and autoGainControl all disabled — undocumented, likely deliberate (these DSP paths can distort pitch tracking), but unconfirmed. Recording the same word twice (once per constraint setting) would confound the comparison with ordinary utterance-to-utterance variation — timing, loudness, pitch — so instead this page opens two concurrent mic streams, one per constraint setting, and captures both from the SAME single recording gesture: you say the word once, and both DSP configurations process that one utterance in parallel. Both resulting takes run through the exact unmodified scoring pipeline (denoise → Praat analysis → feature extraction → classifier), so you can see the gate pass/fail, the fitted pitch coefficients, and the verdict side by side with no variable but the constraint setting itself differing between them.

Run a batch in a quiet room, then run another batch with deliberate background noise (TV, fan, talking) — tag each batch below so the results split by condition, matching Track B/C's Noisy vs. Quiet framing.
